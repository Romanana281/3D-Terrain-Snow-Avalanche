# 3D Симулятор снега и лавин

Интерактивное WPF-приложение для визуализации математических поверхностей с реалистичной физической симуляцией снега и схода лавин.

## О проекте

**SnowPhysics 3D** — это визуально эффектный проект, который отображает различные математические функции в трёхмерном пространстве и добавляет на них динамическую симуляцию снега.

Снег падает на поверхность, скапливается на возвышенностях, формируя сугробы. При накоплении критической массы снега происходит **сход лавины**, которая стекает вниз по склону, деформируя рельеф. Также реализована возможность запускать **кометы** (метеориты), вызывающие снежные взрывы и провоцирующие лавины.

## Возможности

### Математические поверхности
- **Седло** (`z = x² - y²`)
- **Эллиптический параболоид** (`z = x
² + y²`)
- **Волны** (`z = sin(x)·cos(y)`)
- **Гауссов холм** (`z = 4·e^(-(x²+y²)/2)`)

### Физическая симуляция
- Падающий снег с учётом рельефа
- Накопление снега на холмах
- Автоматический сход лавин при достижении критической массы
- Деформация поверхности под воздействием лавин
- Запуск комет (Shift + клик) с эффектом снежного взрыва

### Интерактивность
- Вращение камеры (правая кнопка мыши)
- Приближение и отдаление (колёсико мыши)
- Включение/выключение снега для каждой поверхности
- Запуск комет для провокации лавин

## Технологии

- **Язык**: C#
- **Фреймворк**: WPF (.NET Framework 4.7.2)
- **3D-графика**: `Viewport3D`, `MeshGeometry3D`, `ModelVisual3D`, `GeometryModel3D`
- **Анимация**: `DispatcherTimer`
- **Математика**: расчёт нормалей, билинейная интерполяция, векторная геометрия

## Структура проекта

- `MainWindow.xaml` / `MainWindow.xaml.cs` — главное окно с вкладками
- `Viewer.xaml` / `Viewer.xaml.cs` — основной 3D-контрол (логика симуляции)
- `Snow.cs`, `Hills.cs`, `Avalanche.cs`, `Comet.cs` — модели физических объектов
- `GetCoordinates.cs` — вспомогательный класс для передачи параметров поверхности

## Как использовать

1. Запустите приложение.
2. Переключайтесь между вкладками: **Седло**, **Параболоид**, **Волны**, **Гауссов холм**.
3. Нажмите кнопку **«Вкл. снег»**, чтобы запустить симуляцию.
4. Вращайте сцену правой кнопкой мыши.
5. Приближайте/отдаляйте колёсиком.
6. Удерживая **Shift**, кликните по холму — запустится комета.
